# SubSentry

SubSentry is an Android app that tracks your subscriptions and free trials, and reminds you before they charge you.

- **No login or account** — nothing to sign up for
- **No internet permission** — the app has no way to send your data anywhere
- **No ads**

This repository is used only to distribute release builds (APK). The app itself is closed-source; no source code is published here.

**Download:** see the [Releases](../../releases) page for the latest APK.

**Landing page:** https://subsentry.b-cdn.net/
